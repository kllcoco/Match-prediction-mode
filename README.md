# 电竞赛事预测小模型（LOL + CS）

一个"玩具级"但认真做的电竞预测模型：会**联网同步赛果**、学**英雄联盟 / CS** 的历史比赛，
预测谁赢、几比几、BP 怎么禁，并且**用中文说出理由**。

## 一句话原理

模型有"两条腿"，权重都是从十几万局比赛里**学**出来的：

1. **看胜负（会认人）**：选手级 Elo——不看 KDA，只看"这个人在场时队伍赢得多不多"（扣掉对手和队友强弱），
   像 NBA 的正负值。能抓住 TheShy 这种"数据不好看但对赢有帮助"的选手。
2. **看表现（不认人）**：每个首发最近 20 局的对位伤害差、对位 KDA 差、参团率、死亡率；
   团队最近 15 局的经济占比、推塔/小龙/大龙控制。CS 看击杀-死亡差、ADR、KAST。
   **新选手只要能搜到他的比赛数据，就能算**——这是能泛化到"明年新选手"的部分。
3. **自己决定信哪条腿**：首发里新人越多，模型越依赖"看表现"（这个倾向也是学出来的）。
4. **赛区水位**：不看世界赛也要比较 LCK 和 LCS → 看选手转会（一个在韩国中游的人去北美称霸，说明北美水位低）。
5. **BP**：从真实禁选记录里学，按上野中下辅各选一个；CS 模拟地图禁选。
   **无畏征召**（系列赛里用过的英雄不能再选）：从数据里自动识别哪些赛事用了无畏征召（2025 年起基本都是），
   加入"英雄池深度 × 第几局"特征（越打到后面，英雄池深的队越占便宜，权重由数据学），BO5 逐局计算胜率，
   BP 也逐局推演、排除已用英雄。
6. **观点**：哪个因素对胜率影响最大就先说哪个，再给逐位置对比、反方风险和爆冷可能。

## 怎么用

```bash
pip install -r requirements.txt
```

预测一场（先联网同步最新赛果，再顺便搜网上新闻）：

```bash
python -m esports predict IG Gen.G --update --news
```

CS：

```bash
python -m esports predict Vitality Falcons --game cs
```

对话模式（本地，不调用任何外部 AI）：

```bash
python -m esports chat
```

可以问：`T1 打 Gen.G 谁赢`、`T1 打 BLG 比分`、`T1 vs BLG BP怎么ban`、`BLG 最近状态`、`切换 cs`。

其他：

```bash
python -m esports update            # 联网同步 LOL + CS 最新赛果
python -m esports search T1 Worlds  # 网页 + Liquipedia 搜索
python -m esports backtest lol      # 回测 S1-S15（严格模式）
python -m esports report            # 生成全部中文报告到 reports/
python -m esports.s16               # 预测今年 S16 并存档
python -m esports.s16 grade         # S16 打完后判卷
```

## 训练方式：先"闭卷考试"，再"开卷"

- **严格模式（闭卷）**：训练时**完全看不到**任何世界赛 / MSI / First Stand / CS Major 的比赛，
  站在每届大赛开打前预测 8 强 → 冠军，然后对答案。
- **完整模式（开卷）**：能看到往届大赛 + 本届小组赛/瑞士轮（就像真实的赛前分析）。
- 所有调参都只用「非大赛」比赛来评估，**不拿世界赛答案调参**。

### 新选手泛化测试（`python -m esports.generalize`）

用往年训练、测下一年四大赛区的比赛（2017-2025 滚动）：

| 测试比赛 | 只认名字(Elo) | 只看表现数据 | 正式模型（自适应） |
|---|---|---|---|
| 全部 1.58 万局 | 63.5% | 62.4% | 63.7% |
| 首发里有 ≥2 个新人（182 局） | 64.3% | 70.3% | 67.0% |

新人多的比赛里，"看表现"明显比"认名字"准——说明它学到的是"怎么看数据"，而不只是记住了谁强。

### 答案泄漏审计（`python -m esports.audit`）

逐届检查训练数据里是否混进了当届大赛（换赛事名、换数据源、时区差一天等）：
- LOL：15 届全部 0 泄漏
- CS：查出并修复了两处（2013-2015 数据源日期差一天导致两届 DreamHack 总决赛未被屏蔽；
  2018-2019 挑战者组在数据里叫 "Main Qualifier"）。修复后全部 0 泄漏，上表是修复后的成绩。
- 调参只用「非大赛」比赛评估；但模型结构（要不要某个模块）是看过回测成绩后决定的，这一点算轻度的"看答案选模型"。

### 说实话的部分

- **S1-S3 基本靠猜**：2011-2013 年能找到的比赛太少；2015 年前的老页面也没有选手表现数据。
- **T1 魔咒**：2022-2025 模型连续押 Gen.G，结果都是 T1 夺冠。加了"国际赛超预期"特征（每个选手往届世界赛/MSI
  里比赛前预期多赢多少）：它确实认出 Faker 等人是全场最"大赛型"的选手，整体准确率也小幅提升
  （去掉 T1 的比赛照样提升，不是只记住了 T1），但数据显示这种超预期只有很小一部分能延续到下一届，
  所以 T1 的夺冠概率几乎没变。
- **爆冷没法"预测准"**：好模型的标准是"说冷门有 30% 机会时，冷门真的约 30% 会赢"。见 `reports/upsets_and_bp.md`。
- **BP**：ban 位预测命中率约为随机的 4~5 倍，但没超过"按版本热门猜"——世界赛常换新版本。
- **KDA 骗人**：模型学到 KDA 的权重≈0，真正有用的是对位伤害差、经济占比和死亡控制。
- 解说文字是"按模型账本说话"的模板生成，不是会自由聊天的大模型。

## 数据来源

| 数据 | 来源 |
|---|---|
| LOL 2014-2025 每局数据（含 BP、选手） | Oracle's Elixir（HuggingFace / Kaggle 公开镜像） |
| LOL 2011-2015、世界赛对阵、2026 赛果/首发/选手数据 | [Liquipedia](https://liquipedia.net)（CC BY-SA，按其 API 规则限速访问） |
| 新闻、阵容变动等文字信息 | Bing 网页搜索 |
| CS 2013-2026 比赛（含地图、阵容、veto） | Kaggle 公开的 HLTV 数据集（mateusdmachado、camilohernndez、nafisbarizki、ektarr） |

原始数据不进仓库，`python -m esports.sources` 会重新下载；整理好的数据在 `data/processed/`。
